# Тренажёр: agente d’affari in mediazione

Веб-приложение (PWA) для подготовки к экзамену Торговой палаты. Ставится на экран «Домой»
айфона, работает без интернета. Внутри 3 651 вопрос из `domande.json`, тексты не изменены.

- **Экзамен** — смешанный вариант на время (по умолчанию 40 вопросов, 60 минут, порог 80 %).
- **Лекции** — тренировка по каждой лекции; темы вне пройденного сюда не подмешиваются.
- **Темы вне пройденного** (822 вопроса) и **конкретный тест** по исходному файлу.
- **Работа над ошибками** — вопрос уходит из списка после двух правильных ответов подряд.
- **Статистика** — история попыток, процент по темам, динамика.

Порог сдачи, число вопросов и время экзамена меняются в приложении (⚙️ и экран настройки теста).

## Публикация в первый раз (GitHub Pages)

Нужен бесплатный аккаунт на [github.com](https://github.com).

1. **Создай репозиторий.** На GitHub: **New repository** → имя, например `trenazher` →
   **Public** (на бесплатном тарифе Pages работает только для публичных репозиториев) →
   *Create repository*. README и .gitignore не добавляй.

2. **Загрузи код.** Проще всего через приложение [GitHub Desktop](https://desktop.github.com):
   *File → Add Local Repository* → выбери папку `ПРИЛОЖЕНИЕ` → оно предложит создать
   репозиторий → *Create* → *Publish repository* (сними галочку *Keep this code private*).

   Или в Терминале (подставь свой логин):

   ```bash
   cd ~/Documents/"КУРС РИЕЛТОР"/Тесты/ПРИЛОЖЕНИЕ
   git init -b main
   git add .
   git commit -m "Тренажёр"
   git remote add origin https://github.com/ЛОГИН/trenazher.git
   git push -u origin main
   ```

   Если git спросит пароль — GitHub принимает не пароль, а токен (*Settings → Developer settings →
   Personal access tokens*). Поэтому GitHub Desktop удобнее.

3. **Включи Pages.** В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

4. **Дождись сборки.** Вкладка **Actions** → «Публикация на GitHub Pages». Через 1–2 минуты будет
   зелёная галочка. Если первая сборка упала, потому что Pages ещё не был включён, — открой её и
   нажми **Re-run all jobs**. Сборка сама прогоняет автотесты: если данные битые, публикации не будет.

5. **Адрес приложения:** `https://ЛОГИН.github.io/trenazher/`

6. **На айфоне:** открой адрес в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»**.
   Запусти приложение с иконки один раз при интернете — оно сохранит все вопросы и дальше
   работает без сети.

## Как обновлять

1. Меняешь файлы (например, `explanations.json`).
2. GitHub Desktop: **Commit to main** → **Push origin**. Или в Терминале:

   ```bash
   git add . && git commit -m "Пояснения" && git push
   ```

3. GitHub сам пересоберёт и опубликует (вкладка Actions).
4. На айфоне открой приложение при интернете — внизу появится «Вышла новая версия» → **Обновить**.
   Незаконченный тест при обновлении не теряется.

## Пояснения к ответам

В типе вопроса есть необязательное поле `explanation`. Приложение показывает его после ответа
(в режиме «ответ сразу») и в разборе ошибок. Добавлять можно двумя способами:

- **В `explanations.json`** (удобнее — большой файл с вопросами не трогаешь):

  ```json
  {
    "6ab6f894eb": "Текст пояснения к вопросу с id 6ab6f894eb",
    "b840fb72cf": "Первая строка пояснения\nВторая строка"
  }
  ```

- **Прямо в `domande.json`**: добавить в вопрос поле `"explanation": "…"`.
  Если пояснение есть в обоих местах, берётся то, что в `domande.json`.

`id` вопроса видно в разборе ошибок (внизу карточки вопроса). Пустые пояснения игнорируются.
Переносы строк (`\n`) сохраняются.

## Где хранится прогресс

Только на устройстве, в `localStorage` браузера — никаких аккаунтов и серверов.

- Safari и приложение с экрана «Домой» хранят прогресс **раздельно**. Решай тесты из иконки.
- Если удалить иконку с экрана «Домой», прогресс удалится вместе с ней. Перед этим сделай
  **⚙️ → Сохранить в файл**; восстановить — **⚙️ → Восстановить из файла**.

Публичный репозиторий означает, что приложение и вопросы может открыть любой, у кого есть ссылка.
Твой прогресс никуда не отправляется.

## Для разработки

Нужен Node.js 22+.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # автотесты: данные, варианты, подсчёт результата, ошибки
npm run build    # сборка в dist/
npm run preview  # посмотреть сборку (с офлайн-режимом) на http://localhost:4173
```

Структура:

```
domande.json          вопросы (не редактируются приложением)
explanations.json     пояснения по id вопроса
src/data.ts           загрузка и индексы по лекциям/тестам
src/lib/quiz.ts       подбор вопросов, перемешивание, выбор ответа
src/lib/scoring.ts    подсчёт результата, разбивка по темам, «что повторить»
src/lib/progress.ts   работа над ошибками, статистика по вопросам
src/lib/store.ts      сохранение в localStorage, незаконченный тест, экспорт
src/screens/          экраны
tests/                автотесты (vitest)
.github/workflows/    публикация на GitHub Pages
```
