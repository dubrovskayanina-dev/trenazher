# Промт для Claude Code

Скопируй всё, что ниже разделителя, и вставь в Claude Code, запущенный в той папке,
где лежит `domande.json` — сейчас это `~/Documents/КУРС РИЕЛТОР/Тесты/ПРИЛОЖЕНИЕ`.
Папку можно перенести куда удобно, главное чтобы `domande.json` лежал рядом.

---

Построй мне тренажёр для подготовки к экзамену на agente di affari in mediazione
(лицензия риелтора, Торговая палата Италии). Я открываю его на айфоне и решаю тесты —
как в приложениях для подготовки к экзамену на права.

## Данные

В папке проекта лежит `domande.json` — 3 651 реальный вопрос из официальных банков
Торговой палаты. Структура:

```json
{
  "meta":    { "total": 3651, "sources": 55 },
  "lessons": [ { "id": "Л6", "title": "Diritti reali, obbligazioni — вещные права", "count": 916 } ],
  "banks":   ["IMMOBILIARE", "MERCEOLOGICO", "ROMA"],
  "sources": ["Catasto", "Condominio", "Estimo", "..."],
  "questions": [
    {
      "id": "6ab6f894eb",
      "bank": "ROMA",
      "source": "Condominio",
      "num": 1,
      "lessons": ["Л4", "Л6"],
      "q": "Generalmente il diritto di ciascun condomino sulle parti comuni è proporzionale:",
      "options": ["Alla superficie...", "Alla rendita catastale...", "Al valore..."],
      "correct": 2
    }
  ]
}
```

Важные свойства данных, их нельзя игнорировать:

- **Число вариантов разное.** У вопросов банка ROMA их три, у IMMOBILIARE и
  MERCEOLOGICO — четыре, у одного вопроса пять. Верстай варианты динамически по
  длине `options`, не закладывай фиксированные A/B/C/D.
- **`correct` — это индекс** правильного варианта в `options`, а не буква.
- **У 822 вопросов `lessons` пустой.** Это темы, которые я ещё не проходила
  (urbanistico, società e fallimento, condominio, titoli di credito, diritto di famiglia).
  Не выбрасывай их: показывай отдельной группой «Темы вне пройденного» и включай
  в смешанные варианты по желанию, но не подмешивай в тренировку по лекциям.
- **Один вопрос может относиться к двум лекциям** — это нормально, не дедуплицируй.
- Вопросы на итальянском, интерфейс — на русском. Текст вопросов не переводи и не
  переписывай: на экзамене они будут ровно в таком виде.

## Платформа

Сделай **PWA — веб-приложение, которое ставится на домашний экран айфона**, а не
нативное приложение. Причина: для нативного нужен аккаунт разработчика Apple за 99 $
в год и публикация в App Store, а PWA я просто открою в Safari и добавлю на экран.
Оно должно **работать без интернета** — все вопросы зашиты в сборку.

Стек: Vite + React + TypeScript + Tailwind, `vite-plugin-pwa` для офлайна,
прогресс в `localStorage`. Деплой на GitHub Pages — настрой и объясни, как
опубликовать и как потом обновлять.

## Экраны

**1. Главная**
- Крупная кнопка «Экзамен» — смешанный вариант на время.
- Список лекций из `lessons`: название, сколько вопросов, мой лучший результат, полоса прогресса.
- Отдельно «Темы вне пройденного» и «Выбрать конкретный тест» (по `source`).
- Блок «Работа над ошибками» со счётчиком накопленных ошибок.

**2. Настройка теста** — сколько вопросов, перемешивать ли варианты ответов,
показывать правильный ответ сразу или только в конце, ограничение по времени.

**3. Прохождение**
- Один вопрос на экран, крупный шрифт, варианты — большими кнопками под палец.
- Сверху: номер вопроса из скольки, таймер, полоса прогресса.
- Можно пропустить и вернуться; в конце список непройденных.
- Ответ меняется, пока не нажата «Завершить».
- Прогресс переживает закрытие вкладки — если я вышла на середине, предложи продолжить.

**4. Результат**
- Крупно **СДАЛА / НЕ СДАЛА** и процент. Порог по умолчанию 80 %, вынеси в настройки:
  правила палаты могут отличаться, я уточню.
- Разбор: сколько верно, сколько ошибок, сколько пропущено, сколько времени ушло.
- **Разбивка по темам** — главное на этом экране. Таблица: тема, сколько было,
  сколько ошибок, процент. Темы с результатом ниже порога подсвечены.
- **«Что повторить»** — список тем, отсортированный по числу ошибок, с формулировкой
  вида «Л13 Credito, ipoteca — 7 ошибок из 12, повтори конспект по этой лекции».
- Список всех вопросов с ошибками: мой ответ, правильный ответ, из какого теста вопрос.

**5. Работа над ошибками** — тест только из вопросов, в которых я ошибалась.
Вопрос уходит из списка после двух правильных ответов подряд.

**6. Статистика** — история попыток, процент по каждой теме, динамика.

## Про объяснения

В данных **нет пояснений к ответам** — только правильный вариант. Не выдумывай их
и не генерируй заглушки. Вместо этого:

- Предусмотри в типе вопроса необязательное поле `explanation?: string` и показывай
  его в разборе, если оно есть. Я буду дописывать пояснения к вопросам постепенно,
  и приложение должно их подхватывать без переделки.
- Пока пояснений нет, в разборе ошибки показывай: правильный вариант, название теста,
  к какой лекции относится вопрос, и кнопку «повторить тему».

## Чего не делать

- Не добавляй регистрацию, аккаунты, сервер и облачную синхронизацию — всё локально.
- Не добавляй рекламу, подписки, геймификацию с сердечками и монетками.
- Не сокращай и не редактируй тексты вопросов и вариантов.
- Не придумывай вопросы, которых нет в `domande.json`.

## Как понять, что готово

Проверь и покажи мне результат проверки:

1. Все 3 651 вопрос загружаются, ни один не теряется.
2. Вопросы с тремя, четырьмя и пятью вариантами отображаются правильно.
3. Подсчёт результата верен: собери тест, ответь заведомо известными ответами, сверь.
4. Приложение открывается без интернета после первой загрузки.
5. На экране айфона всё читается без горизонтальной прокрутки.

Начни с плана: что за чем будешь делать. Потом собирай.
